# Beam

Beam continues Orb’s floating Android wallet for ETHGlobal Mumbai. It prepares a payment from visible text, resolves ENS recipients, and lets the payer review and confirm a test payment through BeamPay on the configured EVM network. Above-cap, eligible first-time recipients, changed ENS addresses and external MCP requests can require World ID. World ID approval and device confirmation are separate.

The landing page serves hackathon visitors who want to see the product and try the approval flows. Its examples stay browser-local. The sample names, amounts, risk results, proofs and receipts are illustrative. The browser compares Ethereum Sepolia and Base Sepolia with illustrative ETH amounts. The Android checkout supports one payment network. The website picker changes the simulation only. Beam ENS subnames require the configured registrar. The optional online assistant and World ID need a configured server.

Sources: the repository root README, app network and intent checks, server MCP/approvals documentation, and BeamPay. The checked repo does not include a Beam film or an installable APK release.
