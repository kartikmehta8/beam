Privacy & permissions

On this website

The guided preview, payment, safety and agent examples run in your browser. They use sample text and addresses. Android setup progress is stored locally in this browser.

In the Android app

Email sign-in and the embedded wallet use Privy. When you use online assistance, the app sends your request and selected context to its configured server, which can use Anthropic and blockchain RPC services. You can inspect or exclude captured text. The native capture handoff expires after 120 seconds. Text already consumed can remain in the active Ask session.

Android permissions

  • Display over other apps draws the floating Beam.
  • Accessibility reads visible text when you tap Beam. Copying text is an alternative.
  • Notifications support the foreground overlay service.
  • Battery optimization exemption helps the system keep that service running.

World ID and device confirmation

For an approval-required action, the server verifies a World ID proof linked to the action and wallet. It stores an app-scoped session identifier. BeamPay records a salted hash for the wallet binding. The wallet still needs a separate device confirmation for payments.

Voice and profile photos

Android’s speech dialog handles voice input. Beam can read a payment review aloud. If you upload a profile photo, the configured server stores it and makes it readable by wallet address.
