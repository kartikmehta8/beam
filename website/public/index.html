10 answers

What is Beam?+

Beam is an Android wallet with a floating button over other apps. Tap it to read visible text, check a suspicious message or prepare a test payment. You review and confirm before anything is sent.

Does it work in WhatsApp, email and Telegram?+

These are sample screens. Beam can read text that Android accessibility exposes when you tap it. You can paste the payment details if a screen does not expose its text.

What network does Beam pay on?+

The browser demo lets you compare EVM testnets. The Android app uses the single payment network supported by its source build.

Can I pay someone by ENS name?+

Yes. Beam resolves the name and rechecks it on your phone. With World ID linked and registration configured, you can also claim a Beam ENS subname.

When do I need World ID?+

Beam asks for World ID when a payment is above your cap, comes from an external agent, meets the threshold for a first-time recipient, or a previously paid ENS name points to a different address. You still confirm on your phone.

Can Scam Shield guarantee a payment is safe?+

Scam Shield explains signals such as urgency, requests for secrets and pay-to-receive traps. Check the recipient and amount yourself.

Can an external agent spend on its own?+

An MCP agent can prepare a payment and return a phone review link. The request always needs World ID and separate device confirmation.

Can I use voice?+

Beam uses the Android speech dialog for input and can read review details aloud. Voice input can prepare a request. Approve it separately on your phone.

How can I install the Android app?+

Beam’s repository provides the Android source and build instructions. Open Android setup for the prerequisites and checklist.

Do the website demos move funds?+

The site runs local examples with sample recipients and receipts. No wallet or funds are needed.
